# 动物精灵素材规格说明（美术资源规格 v1.1）

> 修改时间：2026-09-06 11:20 ｜ 适用：《动物集市》动物四向行走素材
> 目标：动物**朝向即运动方向**（对标猪了个猪/挪车系），替换现行"矢量身体 + 箭头指示"的表现。
> 本文档同时是「美术交付验收单」「AI 生成 Prompt 手册（docs/art-prompts.md）」与「程序生成管线
> （tools/gen-animal-sprites.mjs）」的输出约定。
>
> **v1.1 风格变更（2026-09-06 11:20，用户定调）**：风格由"平面矢量"改为 **3D 卡通渲染俯视角**
> （参考：猪了个猪同款——圆润 3D 体、俯视 45°、可见背部/臀部，站在草地上的既视感）。
> `art-draft/` 中的平面矢量草稿降级为占位参考，正式素材按本版规格产出。

## 1. 资源清单

| 项目 | 数量 | 说明 |
|---|---|---|
| 物种 | 6 | 鸡 chicken / 鸭 duck / 兔 rabbit / 羊 sheep / 猪 pig / 牛 cow |
| 朝向 | 4 | up（背面，远离镜头）/ down（正面，露脸）/ left / right（侧面朝向对应方向） |
| 合计 | **24 张** | `{species}_{dir}.png` |
| 稀有(金光)版 | 0（不需要） | 稀有态由引擎叠加金色光环与微光（现有逻辑），不单独出图 |
| 受击白闪 | 0（不需要） | 引擎用色相叠加（tint）实现，不单独出图 |

> 立项预留物种（原型已画：羊驼 alpaca / 孔雀 peacock / 梅花鹿 deer）建议美术按同一规格补齐，引擎无需改动。

## 2. 尺寸与画布

- **单元画布：144×144 px**（游戏内显示约 40~53px，≈3 倍超采样，缩放后边缘锐利）。
- 主体占画布 **~80%**（约 112px 高），四周留 8~12% 透明 padding——预留受击红闪/金光光环空间。
- **所有 24 张的主体位置、比例、脚底基线必须严格一致**（同一网格基准绘制/导出），否则换图时动物会抖动/漂移。
- 锚点：画布几何中心（引擎按中心定位）。

## 3. 格式与体积

- **PNG-32，透明背景**，不带插值锯齿（导出时关掉背景层）。
- 单张 144px 约 8~20KB，24 张合计约 300~500KB——符合微信小游戏首包 ≤4MB 红线；后续可再打 atlas（TexturePacker / Cocos 自动图集）。
- 不接受 JPG（无透明通道）、不接受 SVG 直接进包（引擎侧已按 PNG 管线设计；矢量源文件可另行归档）。

## 4. 风格规范（v1.1：3D 卡通渲染俯视角）

- **风格公式（v1.1）**：**3D 卡通渲染**（Blender/C4D 质感：圆润体积、软次表面、糖果色釉面），
  Q 版大头比例，**俯视 45° 相机**——动物站在草地上、镜头从后上方看的既视感（参考猪了个猪）。
- 四向定义（同一只、同一光照，只转朝向）：
  - **up**：背对镜头——看到后脑/背部/臀部（ pigs 个猪截图里的样子）；
  - **down**：面对镜头——看到脸；
  - **left / right**：身体侧对镜头，头朝对应方向。
- 配色：糖果粉彩（猪粉、鸡黄白、鸭黄、兔白粉耳、羊奶白卷毛、牛白底棕斑），允许 3D 材质带来的柔和明暗。
- **朝向可读性**（核心要求）：不看箭头，仅凭体型/头朝向即可分辨走的方向。
- **禁止**：文字/水印、背景杂物、强投影（可接受极淡接触阴影或不带）、景深/镜头畸变。
- 配套 AI 生成 Prompt（中/英、按物种、网格版与单张版）：见 **docs/art-prompts.md**。
- （v1.0 平面矢量风格废弃；`art-draft/` 旧稿仅作占位与构图参考。）

## 5. 命名与目录

```
assets/art/animals/
  chicken_up.png  chicken_down.png  chicken_left.png  chicken_right.png
  duck_up.png     ...（同构）
  cow_up.png      cow_down.png      cow_left.png      cow_right.png
```

- 命名即契约：引擎按 `{species}_{dir}` 加载（`dir` 与核心逻辑 `Types.Dir` 一致）。美术替换时**同名覆盖即可热更新**，无需改代码。

## 6. 交付验收清单（美术自查）

1. 24 张齐全，命名无拼写错误；
2. 每张 144×144、透明底（无白底/杂色底）；
3. 同物种四向叠帧检查：身体轮廓完全重合（透明度叠加不抖动）；
4. 跨物种风格一致（描边粗细/眼型/配色）；
5. 朝向正确：up 看不到脸、down 必须露脸、left/right 面向对应方向；
6. 主体不出画布、不留 1px 白边。

## 7. 引擎接入约定（代码侧，已预留）

- `AnimalNodeC` 按 `dir` 选择 spriteFrame（换朝向 = 换图，不再旋转/镜像）；
- 常规移动**去掉头顶箭头**（朝向由素材自表达）；吊车瞄准态保留虚线圈高亮；
- 稀有金环、受击红闪沿用现有节点叠加；
- 程序生成管线（`tools/gen-animal-sprites.mjs` + `art-draft/animals/`）产出的是**草稿占位**，
  美术正式素材按同名覆盖即可无缝替换。
