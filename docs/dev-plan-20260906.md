## 一、项目结构总览（2026-09-06 21:46 快照）

**技术栈**：Cocos Creator 3.8.8 + TypeScript（strict）；20 个 TS 文件 / 3,836 行，四层架构。

| 层 | 文件 | 行数职责 | 约束 |
|---|---|---|---|
| core（5+1） | Types / Constants / LevelCfg / Board / GameSession + Seed | 状态机、遮挡判定、订单/发车、难度参数、随机源 | **禁止 import 'cc'**，Node 直跑（难度曲线是核心资产，BalanceSim 依赖） |
| view（11） | GameView / PenView / ParkView / FenceView / AnimalNode / HudView / ToolsBar / Panels / FxService / Draw2D / Ui | 总控接线、动画、面板、矢量绘制 | 本层只接线不碰数值；视觉随机量（rot）在 view 生成 |
| services（2） | SaveService / AdService | 存档（am_level/am_wallet/am_last_result/am_stars）+ Mock 广告层 | 键名与原型一致便于迁移对拍 |
| platform（1） | PlatformAdapter | WxAdapter（留桩）/ DevAdapter，全工程唯一 wx.* 出现点 | 真实广告接入只动此文件 |

**回归基础设施**（tools/sim/）：
- `sim:verify` — core 自身快照对拍（基准 `baseline-snapshot.json`，L1-L12×100 局），core 改动后必须 12/12；
- `npm run sim` — 400 局难度曲线扫描；`npm run sim:check` — 单关 1600 局深测；
- `boundary_check` — T1 同 seed 双跑 / T2 ≥2 硬约束 / T3 末车白盒 / T4 解锁车位 / T5 满载判败白盒（2026-09-06 23:00 增），五项全绿为改造验收线；
- `tsconfig.typecheck.json` — 全工程 tsc --strict 检查（2026-09-06 21:29 新增；存量 13 条宽松用法报错可忽略，只看新增行）。

**文档资产**：PRD 2.0（`animal-market-prd/animal-market-prd.html`，需求最高优先级）｜DEVLOG.md（变更日志，时间倒序）｜docs/ 下评审、对齐、路线图、本计划 4 份。
