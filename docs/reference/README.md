## 阅读方式

4 份 HTML 文档均为**自包含目录**：各自带 `_shared/`（字体、echarts、mermaid）与 `assets/`，
资源引用全是目录内相对路径，**整目录移动不会断链**。浏览器直接打开对应 `.html` 即可。

## 两条不要做

1. **不要把本目录搬进 `assets/`**：Cocos 编辑器会导入全部资源（拖慢 `library/`），
   且 `resources/` 下的资源会**无条件进包**（主包红线 4MB）。同理适用于 `raw-art/`、`art-draft/`、`raw-models/`。
2. **不要把各文档的 `_shared/` 合并成共享目录**：各自独立自包含是刻意设计，便于单目录分发/存档。
