## 10:41 线上对冲修正（用户截图：同列两动物隔空面对面）

**需求**：同一条路线上任意两个动物不方向相对。既有 `hasHeadOnPair`/`breakAllHeadOnPairs` 只覆盖相邻格 2-环，管不到"隔空对峙"——实测 L6 生成链 **31.6%** 的局有线上正对（紧密盘面高发）。

**语义决策**：正对 = 互为对方朝向上的**第一个占用者**（距离任意、中间隔空格也算）；路线被岩石/第三方动物隔开**不算**（各自路线终点是紧邻遮挡者，视觉上不构成面对面）——是相邻版语义的自然超集。

**实现**（`core/Board.ts`）：`firstOnLine`（朝向线上第一占用者）+ `isHeadOnLinePair`/`hasHeadOnLinePair`（检测）+ `breakAllHeadOnLines`（修正）：翻冲突方到"安全方向"（新方向线上第一占用者不朝它；朝场外恒安全），DIRS_ORDER 确定性顺序、**零 rng**；4 向全冲突翻对方；仍失败**放弃该对**（放弃式兜底 + herd.length×4 上限双保险）。收敛性：每次翻转净减 1 对且不产生新对 → 单调下降无死循环，实测 2000 局残留 0。

**接线四处**：`generate()`（breakAllHeadOnPairs 后）+ `useShuffle()`（重排位置邻居全变）+ `useFlip()`（随机重摇朝向）+ `BalanceSim` 机器人 flip 分支（与 core 一致）。

**验证**：density_check T7 扩展三合一断言 **15/15**；新快照 12/12（备份 `baseline-snapshot.20260910-pre-lineheadon.bak.json`）；boundary 5/5、corridor 12/12、rocks 全绿、tsc 13 条存量；曲线 L6-12 一审 59.5-73.8% 带内、0 卡死。chunks 已验证重编译。

## 09:28 修"空车位无车"状态不同步（用户截图 bug）

**现象**：L6 截图——车位 3 显示"空车位"但无新车驶入（金币 0、围栏 0/7、两单 0 进度 = 开局形态）。

**根因（两层）**：
1. `makeOrder` ≥2 硬约束分支：偏向采样（75% 只用"有解锁个体"的种类）锁死唯一 avail=1 的种类 → 单种凑 1 只 → 直接 return null。开局现场：28 只在场、avail 还有 20 只别的动物却 null（openIds 锁死鸡 avail=1）。

**修复（三处）**：
- `core/GameSession.ts` makeOrder：≥2 约束失败改**确定性降级两级**——①全量种类中重选 avail≥2 单种；②无单种≥2 发"两种各 1"（清仓/放生破坏偶性不变量后的真实场态，实测占持续空槽 0.9%）；全量可用 ≤1 才 null（终局合理）。新增 `allIds` 快照（偏向过滤前全量）。
- `core/GameSession.ts` tryDispatch：`return` → `continue`。
- `view/GameView.ts` renderPark：**自愈兜底**——play 态 + 存在 empty 槽就调 tryDispatch（幂等）。剩余空槽唯一合法形态 = totalAvail=0（全部动物被在途订单预定，等装车腾位后自动补）。

**验证**：开局空槽 0/60000（修复前 126/5000@L1）；"两种各1"类持续空槽 106→0；新快照 12/12（备份 `baseline-snapshot.20260910-pre-slotfix.bak.json`）；boundary 5/5、corridor 12/12、density 14/14、rocks 全绿、tsc 13 条存量；曲线 L6-12 一审 60.8-73.0% 带内、0 卡死。MCP 直连 HTTP refresh 成功（cocosMCP ToolSearch 断连时可用 `curl -X POST http://localhost:3000/mcp` 调 tools/call 兜底）。

**方法论沉淀**：数据层 bug 先写探针抓现场再改（"手动再调成功"一条证据就排除了供给不足假设）；分类统计把 11900 次"持续空槽"拆成 98.9% 合理 + 0.9% 真 bug，避免过度修复。
