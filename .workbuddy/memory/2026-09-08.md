## 17:18 视觉残破修复：白→透明键控误伤白色动物本体 → flood fill（第一性原理踩坑复盘）

**问题**：用户截图反馈"动物身体残破"——所有白色部分（兔毛/羊卷毛/白鸭羽毛/牛白腹）严重缺失，只剩深色轮廓。

**根因（自己代码）**：`tools/process-animal-art.cjs` 的 step 3 是"全局白→透明键控"（mx≥240 α=0、≤220 α=255、中间线性）。动物本体白色 RGB 落在 220~245 区间，被键控为 α≈0~50 → 几乎透明。深色 RGB 远低于 220 → α=255 保留 → 视觉上只剩深色轮廓。

**证据**：旧版 chicken A=255 仅 503 像素（0.77%），对应鸡本体应远不止这点。

**修复**：改为 **BFS flood fill + 4 角种子**——只对与边界连通的近白做透明化，动物内部白色（被轮廓封闭、不与边界连通）天然保留。阈值 KEY_WHITE=240。未访问像素 α=255（动物本体完全不透明）。边缘抗锯齿交给 8×8 box filter 自然混合。

**结果**：6 张图 A=255 占比全部 ≥ 5%（鸡 5.3%、兔 14.1%、羊 18.9%、牛 23.3%、鸭 8.5%、猪 8.7%），体积反而降到 258KB（vs 旧 284KB）。

**教训（可复用）**：处理"白底→透明"永远要警惕**动物本体含白色**。全局阈值法必然误伤，正确思路 = flood fill / 边缘检测 / ML 抠图。**第一性原理汇报顺序**：先 A 直方图证据 → 再根因 → 再修复方案 → 再执行，绝不沉默修复。

## 20:35 运动朝向提前切换修复（tween 链构建 vs 播放的经典时序坑）

**现象**：朝下动物在农场内下行时点击，头立即转朝右（末段方向）。

**根因**：walkPath 构建 tween 链的 for 循环里 `cloneSp.angle = ...` 是循环体内**直接赋值**（不在 .call() 里）——构建循环同步跑完瞬间 angle 已被覆盖成最后一段方向，补间链才开始播。上上轮「异步换图→同步 angle」改造引入（旧异步加载延迟掩盖了时序错误）。

**修复（局部，未重构）**：angle 赋值移入每段 `.call()` 回调（补间开始才转向）；第 1 段不赋值保持初始 angle = -CSS_DEG[a.dir]。roadWaypoints 路径结构与初始朝向本就正确，无需重构。

**教训（重要，可复用）**：cocos tween 链是「构建时循环、播放时顺序」——**任何应在播放期生效的状态变更必须放进 .call() 回调**；写在循环体里 = 全部提前到构建瞬间执行。旧代码的异步回调（网络/加载延迟）可能掩盖这类时序错误，改造为同步赋值时会立即暴露。
